# Benchmark results

This directory is for preserved benchmark runs from identified, stable machines.

Do not commit arbitrary laptop or GitHub-hosted-runner measurements as project baselines. A preserved run should include both the hyperfine JSON file and its sibling metadata JSON generated by `scripts/benchmark-metadata.py`.

Recommended layout:

```text
benchmarks/results/
  <machine-id>/
    analysis-r3bench-o2-baseline.json
    analysis-r3bench-o2-baseline.meta.json
    search-r3bench-o2-baseline.json
    search-r3bench-o2-baseline.meta.json
```
